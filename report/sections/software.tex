\subsection{Class overview}
The source code is organized into 6 main components: the \texttt{HMM} class, the \texttt{Emissions} class, the \texttt{Transitions} class, the \texttt{HMMParams} class, the \texttt{Inference} class, and the \texttt{Solvers} class.
All classes except \texttt{HMM} are abstract interfaces.
The \texttt{HMM} class acts as the main entry point, providing a simple interface for training and inference by delegating to the other components.
The key design principle is that concrete implementations of \texttt{Emissions} and \texttt{Transitions} are injected at runtime, allowing different HMM variants to be used interchangeably.
A detailed explanation of each class and the motivation behind the design choices can be found in \ref{section:app:class_design}, and class diagrams are provided in \ref{section:app:diagrams}.


\subsection{Design Principles}
A Object Orientated Programming (OOP) design was chosen for this project to promote modularity, extensibility, and separation of concerns. \newline
The Design Inversion Principle (DIP) was a key principle in the design of the codebase, 
The use of abstract interfaces for the core components of the HMM allows for different implementations to be easily swapped in and out without affecting the rest of the system.\newline
This design also promotes code reuse and makes it easier to extend the project in the future by adding new types of emissions, transitions, or inference algorithms without modifying existing code. \newline
Overall, the OOP design provides a clear structure for the codebase and facilitates future development and maintenance of the project. \newline
\subsection{Primary Libraries}
The primary libraries used in this projects are \texttt{JAX} \cite{jax2018github}, \texttt{EQUINOX} \cite{kidger2021equinox}, and \texttt{Optax} \cite{optax2020github}. \newline
\texttt{JAX} was chosen over \texttt{NumPy} for its automatic differentiation capabilities and performance optimizations. It allows for efficient computation of gradients, which is essential for training the HMM parameters using gradient-based optimization methods. \newline
